Training Dataset

Trained on the CICIDS2017 dataset, combining 8 capture files covering benign traffic and multiple real attack categories.

  • 2,520,798 total flow records
  • 78 original network features
  • 25 features selected (correlation + importance)
  • 2,095,057 benign / 425,741 attack flows
  • Attack types: DoS, DDoS, PortScan, Brute Force, Bot, Web Attacks, Infiltration
Detection Architecture

This system uses a hybrid, layered detection approach:

  1. Blocklist check — known-bad IPs are flagged instantly, no ML needed
  2. ML classification — XGBoost classifies each flow as BENIGN or ATTACK using 25 features
  3. Rate-based rules — tracks connection rate per source IP to catch port scans
  4. Face correlation — network attacks are linked to the physical identity at the terminal
